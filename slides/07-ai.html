EmbedBench, arXiv 2506.11003 · PCEval, arXiv 2601.02404

EmbedAgent / EmbedBench, Xu, Cao, Wu et al., arXiv 2506.11003v2 (22 Jan 2026), ICSE 2026 research track. pass@1 = passes on the first attempt. 55.6%: DeepSeek-R1 with the schematic given (50.0% when it also designed the circuit). 65.1%: the same with retrieval (RAG) and compiler feedback. Migration: Arduino to Pico MicroPython 73.8%, to ESP-IDF 29.4% (Claude 3.7 Sonnet). Misses: 7-segment voltage logic 41-44% of errors on that part, debouncing 39-48%, about 42% syntax or API errors on ESP-IDF. PCEval: Song, Jeon, Lee, arXiv 2601.02404 (31 Dec 2025), 13 models. Not on the slide: Englhardt et al. (CHI EA 2024), GPT-4 wrote working I2C interfaces 66% of the time, and in a 15-person study success at a LoRa sensor rose from 25% to 100%.

Help your agent

  • A good AGENTS.md contains info about the hardware and reference code/projects.
    • You can even ask your agent to do a "deep research" and it's usually pretty thorough.
  • Give it skills:
  • Tell it how to interact with the hardware.
  • Give it a goal and a way to measure it.

main.py: a REPL beside your app


import asyncio, aiorepl

async def main():
    app = asyncio.create_task(sensor_loop())
    repl = asyncio.create_task(aiorepl.task())
    await asyncio.gather(app, repl)

asyncio.run(main())

Skills that reach the board

A skill is a folder your agent loads: a SKILL.md and scripts. In October 2026 these are new, small projects: read one before you install it.

MicroPython, by Andrew Leech

  • mpremote: runs code, copies files, keeps one session open

CircuitPython, by Adafruit

  • circuitpython-runner: runs code, reads its output
  • hw-tests-runner: pytest, on the board

Each agent looks in its own folder: .claude/skills/ for Claude Code, .agents/skills/ for Codex, .github/skills/ for Copilot.
