MicroPython and CircuitPython

MicroPython

A lean Python 3 for microcontrollers, by Damien George.

The best for each chip. machine is the portable core, and each port adds modules for what the individual chip can do.

CircuitPython

Adafruit's fork of MicroPython, for beginners and education.

The same code everywhere. One API on every board; a board that can't support a module leaves it out.

Blinka brings that API and Adafruit's drivers to CPython on SBCs like Raspberry Pi.

Sources: MicroPython libraries · CircuitPython core modules

Where they differ

MicroPythonCircuitPython
Hardwaremachine, plus a module per portboard, digitalio, busio on every board
PinsThe port ids: Pin(15), Pin("GP15")The board's labels: board.D5, board.LED
ConcurrencyPin interrupts, timers, _thread, asyncioNo interrupts or threads; asyncio
WorkflowCopy files with mpremote or ThonnyA USB drive: save code.py and it reruns
FilesYour code reads and writes themRead-only to code, unless boot.py remounts
Librariesmip, from micropython-libcircup, from a bundle
